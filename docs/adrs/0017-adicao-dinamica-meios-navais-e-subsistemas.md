# ADR 0017: Adição Dinâmica sob Demanda para Meios Navais e Subsistemas

## Status
Aprovado / Implementado

## Data
11 de Novembro de 2026

## Contexto
O meio naval e o subsistema afetado devem iniciar vazios e permitir a adição dinâmica através do botão "+ Adicionar Novo", dado que é inviável manter uma listagem estática permanente.

## Decisão de Arquitetura
1. As listas de seleção iniciam vazias.
2. Botões inline "+ Adicionar Novo" alternam para formulário de inclusão imediata.

## Consequências
Flexibilidade total para cadastramento conforme as tripulações reportam fatos.
